# 🃏 Top Magic Cards

Landing page dedicada a las cartas más destacadas de Magic: The Gathering, 
con enlace directo a CardMarket para su compra.

## 🚀 Demo en vivo

[Ver aplicación](https://top-magics-cards.netlify.app/)

## 🛠️ Stack

- React
- JavaScript
- CSS
- Vite
- Netlify (deploy)

## ✨ Funcionalidades

- Muestra las cartas Magic más destacadas
- Enlace directo a CardMarket para comprar cada carta
- Diseño responsive
